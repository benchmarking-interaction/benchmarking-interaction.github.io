How well does a navigation agent ask for help?
QAsk-Nav measures interaction quality separately from navigation success.

Abstract

Collaborative Instance Object Navigation (CoIN) asks an embodied agent to find a specific object described in natural language (e.g. 'The beige bed with a blue comforter near the open window'), using visual observations and dialogue with a user. When several objects look alike, the agent can ask questions to the user to resolve ambiguity. Yet navigation success alone does not tell us how well the agent collaborates.

We introduce Question-Asking Navigation (QAsk-Nav), a reproducible benchmark with separate protocols for question-asking and navigation. It combines a lightweight interaction evaluation, improved navigation target descriptions, and approximately 26,000 quality-checked reasoning and question-asking traces. Using this data, we train Light-CoNav, a unified 7B vision-language model, that can be used on top of any modular navigation policy. It improves question-asking over navigation-ready baselines and generalizes better to unseen objects than AIUTA, while using approximately three times fewer parameters and over 70 times faster interaction inference.

The QAsk-Nav benchmark

Separate evaluations make it possible to study the conversation itself, rather than deriving from slow and expensive navigation simulations.

01

Question-asking

The questioner sees a candidate object and the target description. An oracle has access to the target image. The agent asks free-form questions or decides whether the candidate matches the target.

Multi-turn episodes with hard synthetic distractors · No navigation simulator required

02

Navigation

Evaluate collaborative navigation in Habitat using HM3D scenes, with clearer target descriptions and an improved VLM oracle. The protocol covers seen objects, synonyms, and unseen objects.

~1.6K episodes · 81.6% human preference for the new descriptions

03

QAsk-Nav Dataset

QAsk-Nav-dataset pairs observations and descriptions with reasoning, an uncertainty score, a question when needed, and previous dialogue. It supports training and analyzing interactive agents.

~26K traces · Reasoning supervision · Dialogue context

Light-CoNav

One compact interaction model, coupled to an existing navigation policy.
